Beta v0.2.0, open source under MIT

Let your AI assistant sort all your mail. It can't send or delete any of it.

An MCP server you run yourself. Your assistant can search, read and summarize every mailbox you own (Gmail today), then tidy up with labels, archiving and reply drafts. Every organizing change is recorded and can be undone.

Install GitHub

  • All your mailboxes, one connector

    Link personal, work and side-project mailboxes under short aliases. One question searches all of them at once.

    Learn more about accounts

  • Runs on your server

    One Docker container on a home server or small VPS. Tokens, journal and preferences stay on its disk.

    Learn more about hosting

  • Can't send or delete, and every change can be undone

    Enforced in code and checked by a test. Every organizing change is journaled and can be reverted.

    Learn more about safety

Link mailboxes from your browser

The server has an owner page at /admin. It works on a phone, too.

  • Every linked mailbox with its state, checked when the page loads.
  • Link, re-link or remove a mailbox with no command line and no restart.
  • Only a Google login in ALLOWED_EMAILS gets in, the same rule as the connector.

How linking works

Tested with Claude. Should work with ChatGPT and local models through compatible MCP clients — untested. Client requirements and details

Run it on your own server

Setup takes a Google Cloud project, Docker and an HTTPS address. Reports, fixes and new mail providers are welcome.
